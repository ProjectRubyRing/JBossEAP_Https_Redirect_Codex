5. Gitによる空白検査
   git -c core.autocrlf=false -c core.safecrlf=false
       -c core.whitespace=blank-at-eol,blank-at-eof,space-before-tab,cr-at-eol
       diff --no-index --check
   生成したテキストを空ディレクトリと比較。空白エラー出力なし。
   no-index の終了コード1は、追加ファイルによる差分ありを表す。
   cr-at-eolでWindowsのCRLFを改行として扱い、末尾の空白とは区別する。
   作業フォルダーはGitリポジトリではないため、通常のgit diffは対象外。

   HRESULT 0x80080005（CO_E_SERVER_EXEC_FAILURE / サーバー実行失敗）。
   Excel本体での読み取り専用オープン、印刷・PDF出力は未完了。
   構造検査とPillow描画を代替とした。利用者環境での表示確認が残る。

   Git同梱bashで configure-offline.sh の -n を試したが、
   couldn't create signal pipe, Win32 error 5 で起動に失敗した。
   この失敗により postconfigure.sh の bash -n は実行されていない。
   両ファイルはPOSIX shの形式、引用、終了処理、CLIの受け渡しを静的確認。
   使用するLinuxコンテナで sh -n を実施すること。
